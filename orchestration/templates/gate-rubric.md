# Единая 5-пунктная рубрика приёмки (gate-rubric)

Применяется Гейтом и всеми судьями панели. Каждый пункт оценивается СТРОГО по артефакту на диске,
а не по словам автора. **Зелёный pytest — лишь одно из условий, но не автоматическая сдача.**

| # | Пункт | Что проверяется | Доказательство на диске |
|---|---|---|---|
| 1 | **Спека** | Каждый пункт спецификации выполнен; невыполненный обязан быть назван | `specs/<ID>.md` vs `git diff` |
| 2 | **Diff** | Затронуты только разрешённые спекой пути; нет мусора (`*.bak`, `*.tmp`), нет правок `AGENTS.md` | `git diff main...HEAD --stat`, `--name-only` |
| 3 | **Гейты** | ruff = 0, тайпчекер = 0, pytest зелёный, `alembic upgrade head && alembic check` = 0 (нет дрейфа схемы) | Личный прогон проверяющего + логи |
| 4 | **Риск-план** | Риски R-1..R-N прикрыты named-тестами; графа «не смотрел» заполнена честно | `docs/risk-plan-<ID>.md` + тесты |
| 5 | **Запреты спеки** | Zero Auth Leak (токены/target_url не в логах), нет SQL в роутерах, анти-чит тестов (моки тестируемого кода, `assert True`, `pytest.mark.skip`), `AGENTS.md` не менялся | Тесты утечек, греп, дифф |

## Вердикты
- **READY** — все 5 пунктов `ЗАКРЫТ` → разрешение на мерж.
- **REWORK** — хотя бы один `НЕ ЗАКРЫТ` → возврат Кодеру: файл и строка + команда исправления.
- **ESCALATE** — пакет неполон или противоречив (handoff расходится с diff; падение characterization;
  `@pytest.mark.skip` = Test Anti-Cheat Violation; `PROOF_PACKAGE_INTEGRITY_FAILED`) → решение человека.

## Правила панели (2 из 3)
- Три независимых судьи, каждый пишет голос `.ai-team/panel-votes/gate-{1,2,3}.json` с `verdict`, `finding`
  (при REWORK — файл:строка) и хэшами `spec`/`risk_plan`.
- Кворум: ≥ 2 READY → приёмка; 0–1 → возврат Кодеру (в пределах лимита 3 итераций) или эскалация.
- Голоса принимаются только при совпадающих хэшах входов; дубликат места (seat) отклоняет весь набор.
- Рекомендация: судьи на разных моделях (гетерогенность уменьшает общие слепые пятна).

## CI-минимум допуска к мержу
```bash
test -f .ai-team/verdict.md && head -1 .ai-team/verdict.md | grep -q "Вердикт: READY" \
  && uv run ruff check app tests && uv run basedpyright && uv run pytest -q
```
