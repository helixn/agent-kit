# Скил: monolith-knowledge-graph

## Триггеры
- Любая задача на изменение или добавление функционанала в монолите.
- Нужно оценить радиус влияния правки до написания кода.
- Подозрение на циклический импорт или ошибка `ImportError`.

## Процедура
1. Прочитать только `docs/INDEX.md`, определить целевой домен.
2. Прочитать один паспорт `docs/domains/<домен>.md`: раздел `Location`, нерушимые правила, связи.
3. Выполнить `python3 tools/build_dependency_graph.py --check-cycles`: код возврата обязан быть 0.
4. Выполнить `python3 tools/scoped_retrieval.py --target <модуль>` и загрузить в контекст только модули замыкания.
5. Читать файлы вне замыкания и вне раздела `Location` запрещено.

## Ворота готовности
- [ ] Целевой домен назван, паспорт прочитан.
- [ ] Граф ацикличен (код возврата 0).
- [ ] В контексте только файлы замыкания, не больше пяти.

## Стоп-условия
- Найден цикл: остановиться, сообщить участников цикла, код не писать.
- Для задачи нужен файл вне замыкания: остановиться и объяснить зачем.
