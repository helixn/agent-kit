# Скил: architecture-layers-linter

## Триггеры
- Завершение любой волны, где менялся код.
- Перед юнит- и интеграционными тестами, в пре-коммите и в Techlead Gate.

## Процедура
1. Выполнить `python3 tools/verify_architecture_layers.py` и сохранить код возврата.
2. При нарушении взять из отчёта файл, строку и запретный импорт.
3. Исправить переносом логики в нужный слой или введением `typing.Protocol` в ядре, но не обходом линтера.
4. Дополнительно убедиться: в `app/services` нет импортов `fastapi` и `HTTPException`; обработчики API не обращаются к БД напрямую.

## Ворота готовности
- [ ] Линтер вернул код 0.
- [ ] Направление зависимостей: api, services, core, schemas; обратных импортов нет.

## Стоп-условия
- Попытка обойти линтер динамическим импортом: отклонить правку.
- Попытка добавить `fastapi` в сервис ради статус-кода: откатить правку.
