# Скил: blast-radius-guard

## Триггеры
- Перед каждым коммитом и при завершении волны.
- В составе Techlead Gate.

## Процедура
1. Выполнить `python3 tools/verify_blast_radius.py`: он читает `git status --porcelain -uall`, новые файлы считает поштучно.
2. Сверить число файлов с `max_changed_files` из `specs/blast-radius.json` (по умолчанию 7).
3. Проверить защищённые пути: `app/core/`, `alembic/` и `frozen_paths`. Новый файл в ядре допустим только из `allowed_new_core_files`.
4. При превышении бюджета предложить разбиение на волны без пересечения файлов.

## Ворота готовности
- [ ] Изменено не более 7 файлов.
- [ ] Замороженные пути не тронуты.
- [ ] Скрипт вернул код 0.

## Стоп-условия
- Затронут замороженный файл: откатить его (`git checkout -- <файл>`) и запросить согласие владельца.
- Бюджет превышен: разделить задачу, спецификацию бюджета не менять.
