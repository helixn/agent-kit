# Скил: Модульные тесты доменной логики (tests-unit)

## 1. Назначение и триггеры
- **Применять когда:** нужно покрыть тестами сервисный слой и модули доменной логики (валидаторы, безопасность).
- **НЕ применять:** для проверок SQL, индексов и транзакций — это зона скила `tests-integration`.

## 2. Предусловия (Inputs)
- Защитный слепок `tests/characterization/` зелёный.
- Известны целевые модули (из `architecture-map.md`).

## 3. Пошаговая процедура (Execution Steps)
### Фаза 1: Инвентаризация ветвлений
1. Выписать все `if/else`, `match`, обработку исключений и составные условия целевых модулей.
2. Составить список граничных случаев: счастливый путь, каждая ветка отказа, исчерпание лимитов/попыток, каждый класс опасного входа.
### Фаза 2: Fake-репозиторий вместо моков
1. Создать In-Memory Fake-репозиторий на словаре Python с тем же интерфейсом, что у настоящего (каталог `tests/unit/fakes.py`).
2. НЕ использовать `AsyncMock`/`MagicMock` для проверки вызовов: проверять результат и состояние, а не факт вызова. Фейк содержит только методы, которые реально вызывает сервис (правило минимальной достаточности).
### Фаза 3: Тесты и измерение
1. Написать по одному тесту на каждую ветку из списка Фазы 1 в `tests/unit/`.
2. Запустить измерение: `uv run pytest tests/unit/ -q --cov=<целевые модули> --cov-branch --cov-report=term-missing`.
3. Цикл: читать колонку `Missing` → один тест на пропуск → перезапуск — пока таблица не опустеет.

## 4. Выходные артефакты (Outputs)
- `tests/unit/fakes.py`, `tests/unit/test_<service>.py`, тесты целевых модулей.

## 5. Ворота готовности (Definition of Done)
1. `uv run pytest tests/unit/ -q --cov=<целевые модули> --cov-branch --cov-fail-under=100` возвращает 0.
2. Весь пакет `tests/unit/` выполняется быстрее ~2 секунд без БД и сети.
3. `uv run ruff check tests/unit/` и `uv run basedpyright tests/unit/` возвращают 0.

## 6. Стоп-условия и откат
- Запрещено подключаться к сетевым сокетам и реальной БД в `tests/unit/`.
- Запрещено мокать тестируемый сервис и функцию проверки безопасности.
- Запрещено менять код в `app/`, чтобы подогнать под тест: тест выявил баг — остановиться и доложить человеку (исправление — отдельной задачей под защитой слепка).
