# Скил: Безопасное исследование кодовой базы (investigate-codebase)

## 1. Назначение и триггеры
- **Применять когда:** получена любая новая задача по доработке, рефакторингу или исправлению бага в существующем коде.
- **НЕ применять:** когда задача уже на этапе реализации тестов или миграций (есть профильные скилы).

## 2. Предусловия (Inputs)
- Проект развёрнут, зависимости установлены.
- Рабочее дерево чисто: `git status --short` не содержит незафиксированных изменений.

## 3. Пошаговая процедура (Execution Steps)
### Фаза 1: Разведка структуры (Read-Only)
1. Просканировать дерево каталогов исходников ({{app/api/, app/services/, app/repositories/, app/models/}} — см. проект).
2. Найти все точки входа (эндпоинты/обработчики), связанные с целевой сущностью.
3. Зафиксировать схемы входящих и исходящих контрактов (DTO/Pydantic).
### Фаза 2: Построение карты архитектуры и кода
1. Составить цепочку вызовов сверху вниз: `Endpoint -> Service -> Repository -> Model -> Database`.
2. Выписать все внешние контракты, которые запрещено изменять (пути, статус-коды, поля ответов).
### Фаза 3: Определение зоны влияния правок
1. Сформировать список файлов, разрешённых к изменению (не более 3–5 файлов).
2. Зафиксировать список неприкосновенных модулей ядра (конфигурация, пул соединений, существующие контракты).
3. Если для задачи нужно больше 5 файлов — предложить разбить работу на этапы, а не раздувать список.

## 4. Выходные артефакты (Outputs)
- Файл `architecture-map.md` в корне проекта (шаблон: `docs/architecture-map.template.md`, копируется установщиком agent-kit) с разделами: слои, направление вызовов, внешние контракты, зоны риска, потребители, зона влияния правок.

## 5. Ворота готовности (Definition of Done)
1. `git status --short` по исходным каталогам пуст (код не менялся!).
2. Прямые проверки линтера и типов возвращают 0: `uv run ruff check app tests`, `uv run basedpyright`.

## 6. Стоп-условия и откат
- Изменён любой файл исходников — немедленно `git restore <файл>` и прекратить работу.
- Результат разведки — документ, а не код. Если агент начал «сразу миграцию» — это нарушение такта: ответ отбрасывается.
