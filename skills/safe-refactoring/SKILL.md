# Скил: Безопасный рефакторинг (safe-refactoring)

## 1. Назначение и триггеры
- **Применять когда:** нужно убрать дублирование, выделить модуль, ужесточить типы, не меняя поведение сервиса.
- **НЕ применять:** в одном коммите с изменением бизнес-поведения или новой фичей. Найденный баг во время рефакторинга — в заметки, отдельной задачей.

## 2. Предусловия (Inputs)
- Все тесты и проверки зелёные: `uv run pytest -q`, `uv run ruff check .`, `uv run basedpyright`.
- `git status --short` чист (иначе откат вернёт не к исходной точке).

## 3. Пошаговая процедура (Execution Steps)
### Фаза 1: Фиксация исходного состояния
1. Запустить полный набор тестов и записать зелёный статус.
2. Составить список мест рефакторинга: `grep -r "<имя>" app/ tests/ --include="*.py" -l`.
### Фаза 2: Малые атомарные шаги
1. Один шаг — одно структурное изменение.
2. После КАЖДОГО шага выполнить `uv run ruff check .`, `uv run basedpyright`, `uv run pytest -q`. Тесты заморожены: упал тест — ошибся агент, откат последнего шага.
### Фаза 3: Проверка силы тестов (Bug Injection)
1. Внести одну точечную поломку в бизнес-логику (например, убрать инкремент счётчика, инвертировать проверку флага).
2. Убедиться, что тесты стали красными («мутант убит»). Остались зелёными («мутант выжил») — дыра в проверках: откатить поломку, дописать строгий `assert` отдельным коммитом, повторить посадку.
3. Откатить намеренную поломку, убедиться в чистоте дерева.
Примечание: автоматический аудит силы тестов — инструменты `mutmut`/`cosmic-ray` на отдельной ветке, как периодическая проверка, не как ежедневные ворота.

## 4. Выходные артефакты (Outputs)
- Изменения только в `app/`; папка `tests/` не изменена.

## 5. Ворота готовности (Definition of Done)
1. `git diff --exit-code tests/` возвращает 0 (тесты не тронуты).
2. `uv run ruff check .`, `uv run ruff format --check .`, `uv run basedpyright` возвращают 0.
3. `uv run pytest -q --cov=app --cov-branch --cov-fail-under=<порог>` возвращает 0.

## 6. Стоп-условия и откат
- Запрещено редактировать существующие тесты в `tests/` во время рефакторинга.
- `uv run pytest -q` стал красным — немедленно откатить последний шаг (`git restore app/`), не лечить следствие новыми правками.
- Красный статус повторился 3 раза подряд на одном шаге — остановиться и доложить человеку.
