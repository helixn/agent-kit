# Скил: Причинные данные (data-causal)

## 1. Назначение и триггеры
- **Применять когда:** строятся агрегации (M1→M5/M30/H4), джойнятся признаки, ставятся метки исходов, готовятся датасеты для обучения.
- **НЕ применять:** для чисто инженерных правок без движения данных.

## 2. Предусловия (Inputs)
- Известны источники (провайдер, таймзона, единицы времени), целевые таймфреймы и горизонт меток.

## 3. Пошаговая процедура (Execution Steps)
### Фаза 1: Инвентаризация швов утечки
1. Перечислить все места, где будущее может протечь: агрегация незакрытого бара, join признака «в момент», метка внутри бара, использование пересмотренных провайдером данных.
2. Зафиксировать правило: бакет агрегата закрывается по закрытию последней входящей M1; признак доступен только ПОСЛЕ закрытия своего бара.
### Фаза 2: Причинная реализация
1. Агрегации — только по полностью закрытым барам; last-бар текущего незакрытого интервала исключается.
2. Джойны — asof по времени доступности признака (левое соединение назад), никакой подмены на «known at end of day».
3. Метки — исход в горизонте ПОСЛЕ закрытия фиче-бара; метка belongs to моменту закрытия фиче-бара.
4. Таймстемпы: единые UTC; единицы проверены (мс против мкс — типовой сдвиг на дни при делении на 10**6 вместо 10**3); NaN-политика зафиксирована.
### Фаза 3: Независимая сверка (обязательна)
1. Пересчитать выборочно агрегаты/метки вторым независимым путём (другой код/ручной расчёт) и сравнить числа: таймстемпы, значения open/close, распределение меток.
2. Сверить с внешним источником по контрольным точкам (несколько дат, конкретные значения).
3. Зафиксировать манифест данных: период, источник, hash/версия, правило агрегации.

## 4. Выходные артефакты (Outputs)
- Датасеты/агрегаты с манифестами; отчёт сверки (таблица: точка контроля → ожидание → факт).

## 5. Ворота готовности (Definition of Done)
1. Отчёт независимой сверки: расхождений нет (или расхождения объяснены и устранены).
2. Манифесты данных закоммичены.
3. Spot-чек «заглядывания»: сдвиг фиче-бара на +1 такт меняет признаки (иначе фича украла будущее).

## 6. Стоп-условия и откат
- Найдена утечка — данные помечаются недействительными до фикса; уже обученные на них модели не используются.
- Сверка таймстемпов с независимым источником обязательна для ЛЮБЫХ новых загрузчиков/конвертеров (типовой баг — сдвиг всех дат).
- Нельзя «подкрутить» сверку под факт: расхождение — сигнал об ошибке, а не о данных.
