# Скил: Протокол эксперимента (experiment-protocol)

## 1. Назначение и триггеры
- **Применять когда:** планируется любое обучение/перебор гиперпараметров на исторических данных.
- **НЕ применять:** для точечных инженерных правок без обучения (есть `small-fix`).

## 2. Предусловия (Inputs)
- Данные прошли аудит причинности (скил `data-causal`).
- Известен реестр потреблённых периодов; определены девственные периоды для финальной оценки.

## 3. Пошаговая процедура (Execution Steps)
### Фаза 1: Заморозка протокола (до любого fit)
1. Зафиксировать в файле `experiments/<имя>/PROTOCOL.md`: состав данных и периоды, окна, полный список фич,
   целевая метрика (AUC / EV×n / WR — выбрать ДО прогона), порог гейта, сиды, версии библиотек.
2. Определить ролe периодов: TRAIN / VAL / CALIB / TEST; TEST — девственный, один прогон.
3. Протокол коммитится. Правки после первого результата = НОВАЯ версия эксперимента (имя + суффикс).
### Фаза 2: Прогон
1. Preflight вычислений: CUDA доступна, память свободна, лимиты мощности в норме, один сид = одна карта.
2. Длительные переборы — распределённо (dask), с чек-пойнтами и resume (cells.jsonl), крэш-безопасно.
3. Выбор конфигурации — только по VAL/CALIB; TEST не трогается до финала.
### Фаза 3: One-shot оценка и отчёт
1. Финальная конфигурация прогоняется на TEST РОВНО ОДИН раз.
2. Отчёт: метрики по протоколу, сравнение с гейтом, что потреблено, урок (даже при FAIL).
3. Результат хуже гейта → эксперимент закрыт и уходит в архив с уроком; дообучивание того же — запрещено.

## 4. Выходные артефакты (Outputs)
- `experiments/<имя>/PROTOCOL.md`, лог прогона, финальный отчёт, обновлённый реестр потреблённых периодов.

## 5. Ворота готовности (Definition of Done)
1. PROTOCOL.md существует и закоммичен ДО первого лога обучения.
2. TEST использован один раз (проверка по логам/артефактам).
3. Отчёт содержит числа по зафиксированной метрике и вердикт гейта.

## 6. Стоп-условия и откат
- Обнаружена утечка/потреблённый период в TEST — эксперимент недействителен: полная остановка, фиксация урока.
- «Ещё один прогон TEST, вдруг повезёт» — категорически запрещён (это подгонка).
- GPU/CUDA недоступна — стоп, а не CPU-fallback.
