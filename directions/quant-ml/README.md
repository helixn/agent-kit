# Направление: quant-ml (квант/ML-исследования и торговые эксперименты)

Переносит дисциплину экспериментов на рыночных данных: протокол замораживается ДО обучения,
оценка — one-shot на девственных периодах, данные — причинные (без заглядывания в будущее).

## Нерушимые правила направления
1. **Протокол эксперимента замораживается до fit**: данные, окна, фичи, метрика, порог гейта. Правки после результата = новая версия эксперимента.
2. **Потреблённые периоды не переоцениваются** как независимые: ведётся реестр потреблённых периодов; девственные — только one-shot по решению владельца.
3. **Данные причинные**: агрегации только по закрытым барам, asof-join без утечек, метки — из горизонта ПОСЛЕ закрытия бара (скил `data-causal`).
4. **Вычисления**: обучение только на CUDA (CPU-fallback запрещён); длительные переборы/гриды — распределённо (dask), не последовательным прогоном одной машины.
5. **Никаких реальных сделок**: только paper/demo-контуры, если иное не явная команда владельца.
6. **Метрика эксперимента фиксируется в протоколе** (AUC/EV×n/WR): выбор по VAL/CALIB, а не по TEST.

## Definition of Done (ворота направления)
```bash
# чек-пойнт воспроизводимости: протокол, сиды, версии данных зафиксированы в артефактах эксперимента
uv run pytest tests/ -q          # юнит-тесты фич/агрегаций
uv run python -m <verify_data>   # причинность: пересчёт меток/агрегатов независимым путём
# GPU-прогон: preflight (свободная память, лимит мощности, one-GPU-per-run) перед каждым обучением
```

## Порядок скилов
1. `investigate-codebase` — карта пайплайна данных (источники → агрегации → фичи → метки → модель).
2. `data-causal` — аудит причинности данных/меток ДО любого обучения.
3. `experiment-protocol` — заморозка протокола и one-shot оценка.
4. Результаты хуже гейта → эксперимент закрыт («архив с уроком»), не «дообучиваем».

## Специфика против web-fastapi
Здесь главные риски — не HTTP-контракты, а **тихая утечка будущего** и **подгонка под потреблённые данные**.
Поэтому ворот-«маятник миграций» заменён проверками причинности и реестром периодов; ревью-конвейер
(`pipeline`) обязателен для любого эксперимента, чей результат пойдёт в бой.
